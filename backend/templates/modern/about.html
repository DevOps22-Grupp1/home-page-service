About the scam

What this is

Scamazon is a DevOps group project from 2023: a web shop split into small services that each run in their own Docker container. Nothing here is for sale; the deals are as real as the robots.

The home page is Python Flask. It talks to three services over HTTP, and they share one MongoDB.

The parts

  • home page: Flask, the pages you see, sessions
  • products: the catalogue and its categories
  • users: accounts, hashed passwords
  • orders: carts and orders
  • MongoDB: one database for all three

Built and deployed with Docker Compose and GitHub Actions; a smoke test signs up, shops and pays before every deploy.
